PC: double click = place spawner (any mode) · drag = draw wall · drag on/near a ball = push it · right click = delete wall/spawner under cursor · hold right + move = pan camera · scroll = zoom · click = select · touch: long press = place spawner, double tap = re-drop balls, two fingers = pan, pinch = zoom · fully zoomed out = whole field in view · Spawner = Synth or Sampler (record + start point, or FM with 4 modulators) · Settings: scale + root + octaves + field width/height + voices/steal · Pitch = position on the canvas (center = A4, full field height = set octaves, zoom-stable) · zooming in mutes what you can't see (down to -8 dB) · sound pans with the collision spot (max 75%) · Multiplayer: Host game makes a 5-character room code, your friend opens the same URL and joins with that code · per turn: place 1 wall or 1 spawner (deleting is free, deleting your own build lets you rebuild), End turn = the button in the bar at the bottom · pushing balls is off in multiplayer (worlds stay identical)
